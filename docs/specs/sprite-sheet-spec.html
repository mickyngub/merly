Sprite Sheet Spec

Adding sleeping and excited rows to all three mascot sheets

Overview

Each mascot sheet (clawd-sprite.png, codex-sprite.png, kimi-sprite.png) grows from 4 mood rows to 6. The canvas width stays the same. Only the height changes.

Current

512 × 512 px

4 rows × 4 cols = 16 frames

128 × 128 px per frame

New

512 × 1024 px

8 rows × 4 cols = 32 frames

128 × 128 px per frame (unchanged)

Grid Layout

Rows run top-to-bottom (mood), columns left-to-right (animation frame). Append the two new rows at the bottom — do not reorder existing rows.

Animation Specs

4 frames per row, played at ~5 fps (200 ms/frame) in a loop. Each frame is 128 × 128 px on the sheet. Frames are numbered 0–3 left to right.

😴

Row 4 — sleeping

Quiet, dormant. No session active, no recent use.

Mood

Peaceful, still. The creature is resting — not sad or empty, just quietly waiting for the next session.

Frame-by-frame

F0

Eyes closed. Body neutral. Zzz float starts low.

F1

Slight inhale — body 1–2px taller. Zzz drifts up a step.

F2

Exhale — body returns to neutral. Zzz near top, starting to fade.

F3

Full exhale — body slightly squished. Zzz gone, new one appears low. Back to F0.

Key visual rules

  • Eyes must stay closed across all 4 frames — no blink cycle
  • Zzz floats upward and cycles (low → mid → high → disappear + reset). One or two small z pixels is enough at this scale
  • Breathing motion is very subtle — 1–2px body height change max
  • No sweat drops, no open mouth
✨

Row 5 — excited

Fresh session started. Active but barely any usage yet.

Mood

Ready and raring to go. The creature just woke up to a new session — high energy, no stress yet.

Frame-by-frame

F0

Upright pose. Eyes open and bright. Sparkle dots visible above eyes.

F1

Small lean forward or ears perk up. Sparkles shift / twinkle (alternate pixel).

F2

Bob up 1–2px. Big cheek blush prominent. Sparkles bright again.

F3

Settle back down. Sparkles dim slightly. Returns to F0 energy.

Key visual rules

  • Eyes open throughout — no drooping, no heavy lids
  • Big smile and wide cheek blush (wider than happy row)
  • Two small sparkle/star pixels above the eyes — these should twinkle by alternating between bright and dim across frames
  • The drawn critter uses the accessory color (A) for sparkles — match this in the sprite art so the palette recolor looks consistent
  • No sweat, no tired lids

Idle emote rows (6 & 7)

These rows are never a persistent mood state. A mascot randomly flashes them as brief expressions every 5–12 seconds (0.8–1.6s each), so it feels alive between data refreshes. They work the same as the existing emote system that already flashes rows 0–3 — rows 6 and 7 are simply added to that pool.

The flourish is per account, not per surface: MascotAnimator keys a provider's idle column and emote on its config id, and the menu bar, the card, and the collapsed rail all read that one clock. So an account winks in every place it is drawn at the same instant — a critter that flourished up top while sitting flat on its own card read as two different critters.

emote pool: [0, 1, 2, 3, 6, 7] — sleeping (4) and excited (5) are excluded
😉

Row 6 — wink

Playful, cheeky. Flashes briefly on the topnav mascot.

Frame-by-frame

F0

Both eyes open. Happy pose — this is the "before".

F1

Left eye beginning to close (half-squint). Right eye stays open.

F2

Full wink — left eye closed (flat line), right eye wide open. Cheeks up, big smile. This is the held expression.

F3

Left eye reopening. Back toward F0 — expression releasing.

Key visual rules

  • Left eye winks, right eye stays open throughout F1–F3
  • Cheeks prominent (wide, like happy) — this should read as happy + cheeky
  • Big smile on F2 (the held wink frame)
  • F0 can literally be a copy of happy row F0 — it's just the entry frame
🤔

Row 7 — curious

Noticing something. A brief glance upward then back.

Frame-by-frame

F0

Normal forward gaze. Neutral expression — the "before".

F1

Eyes shift up-right. Mouth stays flat. Small "!" or dot appears near top-right of head.

F2

Eyes fully up-right, held. Slight head tilt if possible at this scale. "!" marker bright.

F3

Eyes returning to forward. "!" fades. Back toward F0.

Key visual rules

  • Both eyes shift together — never asymmetric here (that's wink's territory)
  • Direction: up and slightly right reads as "noticing something above/nearby"
  • The attention marker (1–2 pixels in the accent-tinted sweat color S) is optional but helps at small sizes
  • No sweat drops, no worried expression — this is curiosity not stress
  • Mouth stays flat or very slightly open; no smile, no frown

Recolor Compatibility

The app duotone-tints every frame toward the provider's accent color using a luminance ramp: dark pixels → shadow tint, mid pixels → accent, light pixels → highlight. Art should be drawn with this in mind.

Dark pixels (lum < 0.5)

→ Shadow of accent

Use for outlines, eyes, dark shading

Mid pixels (lum ≈ 0.5)

→ Accent color

Use for body fill — this is your color

Light pixels (lum > 0.5)

→ Highlight of accent

Use for belly, cheeks, highlights

Watch out: Avoid pure white (#FFFFFF) for anything that should pick up the accent — it maps to near-white regardless of color. Use a light-grey or cream value instead. Pure black for outlines is fine; it maps to the darkest shadow of the accent.

Delivery

Format: PNG with transparency (RGBA). No white background.

Size: 512 × 1024 px (same width, 512px taller — 8 rows × 128px).

Naming: Replace the existing files in Sources/Merly/Resources/ — same filenames, new content.

Pixel art scale: Each art pixel = 8×8 canvas pixels (128px frame ÷ 16 art pixels). Keep pixel edges crisp — no anti-aliasing on the pixel grid itself, only on the frame boundary if needed.

No code change required — SpriteSheet.swift will be updated to auto-detect row count from the image height, so dropping in a 512×768 sheet is enough.
